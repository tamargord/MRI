# Submission steps

The repository contains the implementation, build/run instructions, SRS, algorithm, datasets, tests, benchmark logs, and linked MP4 demos.

1. Replace `REPLACE_WITH_STUDENT_ID(S)` in [submission.txt](submission.txt) with the submitting student ID(s). Do not submit the placeholder.
2. Check that https://github.com/tamargord/MRI is public and accessible while signed out. Anonymous GitHub API access returned HTTP 404 on 2026-11-04, so public visibility is not verified.
3. Upload the completed text file to Moodle Ex1.
4. Complete the [assignment submission form](https://docs.google.com/forms/d/e/1FAIpQLSdSD-CSNag3QhCp5x778sjDGqxoOb8zUkGTQL8_aA_G6eJfrw/viewform?usp=publish-editor).

The form link is copied from the added assignment page. No Moodle upload or form submission has been performed. The deadline stated on page 3 is November 8.
